# Fotos do espaço

Coloque aqui as fotos do Quati (.jpg, .png ou .webp). Elas aparecem sozinhas no site:

- a **primeira** (em ordem de nome) vira o fundo do topo da página inicial;
- as **até quatro seguintes** formam a faixa de fotos da página inicial (com menos de 3 fotos, a faixa some).

Dica: numere para escolher a ordem (`01-quadras-noite.jpg`, `02-bar.jpg`…). Para o topo, o ideal é uma foto deitada com pelo menos 1600px de largura; para a faixa, fotos quadradas de 500px ou mais. Prefira o arquivo original (não print de tela) e evite salvar de novo em JPEG, que perde qualidade.
